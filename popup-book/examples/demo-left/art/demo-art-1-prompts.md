# 電流與電阻：美術素材 demo-art-1

## Instructions for Codex

Generate every image listed below and save them as PNG files in a new folder named `demo-art-1/`.

1. Use each entry's prompt exactly as written, at its size, with the highest quality setting available. If a larger size with the same aspect ratio is available, use the larger one.
2. When transparent_background is true and the image tool supports it, request a transparent background; otherwise keep the pure white background the prompt asks for.
3. Style lock: generate `01-battery.png` first. Then attach it as a reference image to every other entry, if the tool accepts input images, and append: "Match the drawing style, line weight and colour palette of the reference image exactly; do not copy its subject."
4. Check every result by looking at it. Regenerate (up to 3 attempts per entry) when any of these is true:
   - it contains any writing: characters, letters, numbers, seals, signatures or watermarks;
   - the subject is cut off by or touches the image edge;
   - a subject meant as a flat front elevation is drawn in perspective or three-quarter view, or there is ground, a cast shadow or background scenery;
   - subjects on a sheet overlap each other;
   - a wire, terminal or part is invented or physically impossible;
5. Keep the exact file names. Do not crop, upscale, recolour or otherwise post-process.
6. When finished, write `demo-art-1/manifest.txt` listing each file, its final size and how many attempts it took, then zip the folder as `demo-art-1.zip`.
