# 物理、數學、工程

範例：`examples/demo-left`（左翻測試書：歐姆定律、焦耳熱；圖是程式畫的佔位圖，真的書要用 Codex 的圖）。

## 書的形式

- 左翻、橫書：`book.json` 的 `"binding": "left"`、`"latinFont": "EB Garamond"`，封面 `"style": "label"`（橫的書名籤）+ `"subtitle"`（英文書名）。
- 每個跨頁用 `hTextBlocks({ x: -0.6, y: 0.43, w: 0.5, kicker, title, body, caption })`，文字在左頁、場景在右頁。
- `body` 是段落（字串）和公式（`{ eq: 'P = I^2 R', size: 0.034 }`）交錯；公式是 TeX，用 MathJax 排成向量圖。
- `[[...]]` 包起來的字用強調色（術語第一次出現時用）。

## Chimmy 的寫法偏好（一定要照做）

- 中文敘述，**術語用英文**（current density，不要寫「體電流密度」）。
- 公式裡的文字標籤一律英文（`R_{eff}`，不要在公式裡寫中文）。
- 推導像聊天一樣一步一步：每步先一句說要做什麼，接式子，再一句結果；不要「一行式子配一大段文字」。
- 描述運算要寫清楚對哪個量做（「單位體積的發熱功率乘上厚度 t」，不能只寫「乘上厚度」），換算附單位變化。
- 不用比喻描述技術概念，術語定義明確、固定使用。
- 推導要能用英文講出來（口試用）：旁註可以放一句他能直接說的英文，例如 `Say it: "The dissipated power scales with the square of the current."`
- 不要叫他寫程式。

## 一個跨頁 = 一個觀念 / 一步推導 / 一個實驗

- 場景是**實驗裝置或物理情境**：電路、樣品、探針、光路。平面上畫導線、場線、座標；立起來的是器材和人。
- 機關就是實驗：**拖一個控制量**（滑桿、旋鈕）或**點一下開關**，畫面要**定量地**照物理變化：亮度 ∝ I²、粒子速度 ∝ I、偏轉角照公式算。不能只做「大概往那個方向變」的假動畫。
- 數值一律用程式算（Python 驗算後寫進 JS，或直接在 JS 裡用同一條公式），不要手算、不要為了好看挑數字。

## 核對

1. 每條公式自己推一遍，檢查單位、正負號、適用條件（寫在正文或旁註）。
2. 數值例子用 Python 算過；圖表或動畫的比例跟算出來的一致。
3. 資料來自論文時，明講能不能讀到全文、還是只有摘要。
4. 寫進 `sources.md`：教科書章節、論文、或 Chimmy 自己的推導文件。

## 美術

- 風格範本：19 世紀物理教科書銅版畫（Ganot's *Elements of Physics*），淡彩。見 `examples/demo-left/art/prompts.py`。
- 器材要真實：端子、螺絲、導線接法都對，不要虛構零件（寫進 `reject`）。
- 抽象的東西（場、電流、能量）不要畫在圖上，用引擎做：粒子（`glowMesh` 沿路徑跑）、光暈、平面上的線。

## 可以重用的程式

- `alongPath(pts, u)`（`demo-left/spreads/10-ohm.js`）：沿折線取點，做電荷、光子、流線。
- 拖曳滑桿：`dragStart / dragMove` 只用 x，`clamp` 在軌道範圍內，換算成物理量。
- 發熱、發光：直立的 `glowMesh` 放在卡片前面，`material.color` 換顏色，`opacity` 跟物理量連動。
