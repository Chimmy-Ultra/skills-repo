# 版面：座標、卡片、文字、光線

## 座標

- 一個跨頁是平面圖（plan）：`x ∈ [-2/3, 2/3]`，書脊在 `x = 0`；`y ∈ [-0.5, 0.5]`，**北在上**。
- 版框內緣離頁邊 0.03 → 能放東西的範圍大約 `|x| ≤ 0.637`、`|y| ≤ 0.47`。
- 一律用**讀者座標**寫（左翻書也一樣，引擎自己處理鏡像）。
- 卡片站在 `(x, y)`，**面向南（讀者）**，從腳那條線往上立起來。平面上畫的東西（街道、河、電路）是俯視圖；立起來的卡片是正立面。所以朝東西向的東西（南北向的橋、南北向的長廊）不能用卡片立，要畫在平面上，或另外放一張立面小插圖（見 `examples/bianjing/spreads/60-night.js` 的州橋）。

## 卡片在螢幕上佔多高（最常出錯的地方）

攝影機從南方斜上方看（傾角 46°）。高度 `z` 的點落在螢幕上的位置大約是：

```
screen_y ≈ y + z · (y + 2.3) / (2.22 − z)
```

一張站在 `y`、高 `h` 的卡片，螢幕上從 `y` 一路佔到大約 `y + 1.15h`（頁面南邊）到 `y + 1.3h`（北邊）。

- **螢幕頂端是 `y = 0.5`**，橫拿手機時再上面就切掉了。所以北邊的建築要往南放、或縮小：例如 `y = 0.19`、`h = 0.2` 的宣德樓，頂在 0.44。
- 飛在空中的東西（鶴、氣球）同樣用這條式子算，不要把軌道放到 `z = 0.35` 這種高度。
- 卡片會蓋住它**北邊**一段螢幕範圍內的東西（文字、label、其他卡片）。
- `tools/shot.py <book> audit` 會實際投影每張卡片，列出出界和蓋到文字的。

## 卡片尺寸參考（世界單位，頁高 = 1）

| 東西 | 尺寸 |
|---|---|
| 人 | `h` 0.04–0.055（騎馬、扛東西 0.06–0.066） |
| 小攤、小船 | `w` 0.06–0.11 |
| 一般房子 | `w` 0.11–0.2 |
| 主角建築 | `w` 0.3–0.44（注意頂端） |
| 樹 | `h` 0.08–0.15 |
| 長條（城牆、長廊） | `w` 0.34–0.78，可同時給 `w` 和 `h` |

同一頁的東西比例要一致（人和門的比例）。

## 卡片的狀態

- `rise = 1` 站著；`rise = 0` 往北平躺、圖面朝上。**從正上方看，平躺和站著幾乎一樣**（只差陰影），所以「打開才出現」的東西要用 `held` + 縮放（見 `mechanisms.md` 的 reveal）。
- 翻頁時卡片先摺平、印到紙上一起翻。翻到新的一頁時卡片從北到南依序立起來（`riseWith` 可以讓幾張一起立）。
- `mirror: true` 左右翻轉圖。`rot` 在平面上轉角度（度）。`z` 讓卡片腳離地（掛在屋簷下的燈籠、站在橋面上的人）。`parent` 掛在另一張卡片的 root 上，跟著它移動。

## 文字放哪裡

**右翻（直書）**，用 `textBlocks`：

- 標題欄在右頁，`x ≈ 0.62`（標題欄右緣），`y ≈ 0.0–0.08`（頂）。後面接時辰（紅字）和正文 5 欄。正文從 `x ≈ 0.53` 往左排到大約 `0.2`，往下到 `y ≈ -0.35`。
- 旁註（`caption`）通常放左頁，`x ≈ -0.33 ~ -0.37`，6–7 欄、每欄 ≤ 13 字；要留意它的底不能低過 -0.47。
- 右頁上半（`y > 0.1`）和左頁其他地方放場景。

**左翻（橫書）**，用 `hTextBlocks`：

- 文字放左頁：`x = -0.6, w = 0.5, y = 0.43`；kicker → 標題 → 正文（段落和公式交錯，往下流）。
- 旁註 / 出處放左頁底部（`caption: {x, y, w, paras}`）。
- 右頁放場景。

共通：

- 右上角有全螢幕、聲音按鈕；底部中間有提示列。重要的東西不要放那兩塊。
- 平面上的地名用 `label()`（直）/ `hlabel()`（橫）；label 也會被 audit 檢查有沒有被蓋到。
- 字型：中文是王漢宗中行書（Chimmy 指定）；`latinFont: "EB Garamond"` 時英文用 EB Garamond。build 會列出「字型裡沒有的字」，那些字會用備用字型顯示。

## 平面圖工具（`plan(c)`）

`c = { g, k, T, L, path, band, line, fill, water, road, label, hlabel, wash, img, rnd, text }`

- `line(pts, color, width, dash)`、`fill(poly, color)`、`band(pts, hw)` → 多邊形。
- `road(pts, hw, {tone, edge, pave})`：路，`pave` 是鋪面接縫間距（0 = 不畫）。
- `water(poly, light, dark, scale)`：水面紋理（book 有 `water` 圖就用它，沒有就用程式畫的）。
- `wash(poly, color, blur)`：暈染。
- `img(id, x, y, w, box)`：把 `PLAN_IMG[id]`（spread 的 `planImages`）印在平面上；`ATLAS[name]` 是一張圖裡很多小東西的框（例如荷葉）。
- `text(block)`：印一個文字區塊（直書、橫書、公式都行）。
- `rnd()`：固定種子的亂數，畫紋理用。
- 低階：`g` 是 canvas 2D context，`T(x, y)` 把平面座標轉成像素，`L(len)` 轉長度。

## 光線

每個跨頁的 `light: { el, az, sun, sunI, amb, ambI }`：太陽仰角、方位（`az > 0` 從東邊照）、顏色和強度。翻頁時兩頁之間會內插。

- 白天：`{ el: 42–52, az: ±30–60, sun: '#fff0d8', sunI: 0.62–0.66, amb: '#e8eaee', ambI: 0.72–0.74 }`
- 黃昏：`{ el: 14–15, az: -72, sun: '#ffb070', sunI: 0.72, amb: '#dccabf', ambI: 0.6 }`（影子很長）
- 夜晚：`{ el: 40, az: -22, sun: '#a3b4e2', sunI: 0.26, amb: '#97a3c4', ambI: 0.56 }`，加暖色點光源（`env.light`），文字還讀得到。
