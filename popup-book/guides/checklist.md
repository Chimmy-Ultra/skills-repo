# 交件前的檢查

每一項都要真的做，不能靠印象。

## 自動檢查

- [ ] `python3 tools/build.py <book>`：沒有 `MISSING ART`；「字型裡沒有的字」那一行看過，必要時換字。
- [ ] `python3 tools/shot.py <book> audit`：乾淨。出現的每一條都修掉，或確認是誤報（寫進回報）。

## 用眼睛看（Read 每一張截圖）

- [ ] `shot.py <book> spreads`：每一頁都看。
  - 頂端有沒有東西被切掉（建築屋頂、樹梢、旗子）
  - 有沒有東西浮在半空、或卡進別的東西裡（停在屋脊上的鳥、站在船篷上的人、掛在屋簷下的燈）
  - 字有沒有被蓋到；label 是不是貼在它要標的東西旁邊
  - 平面圖跟卡片有沒有打架（平面的色塊從拱橋底下露出來之類）
  - 整頁的空間分配：有沒有一大片空白、或擠成一團
- [ ] 每個機關都用 `steps` 截好幾個時間點：開始、中間、結束，以及**動畫進行到一半時翻頁、再翻回來**（`reset` 有沒有還原乾淨）。
- [ ] 至少一次用真的滑鼠事件拖曳與翻頁（左翻書尤其要測：往左拉右頁翻下一頁、拖曳方向正確）。
- [ ] 夜景 / 黃昏的頁面：字讀得清楚。
- [ ] 封面、封底。

## 內容

- [ ] 每一句引文都對過原典（歷史）、每條公式和數字都驗過（理工）、每個字詞用法都查過（英文）。對不到的拿掉。
- [ ] 正文沒有把 A 地的事說成 B 地的事、沒有把不同版本的字混用（記在 `sources.md`）。
- [ ] 畫面裡的東西跟正文一致（說「五個門洞」，圖就要五個）。
- [ ] 每個跨頁都有 `sr`（螢幕閱讀器文字）。

## 回報給 Chimmy

- 一句話說做好了什麼，artifact 卡片會附連結（不要貼網址）。
- 列出有疑慮或做不到的地方，集中在一兩句講清楚。
- 測過什麼、沒測過什麼要老實講（例如「只在模擬瀏覽器裡測過，沒在真的手機上翻」「音效沒有實際聽過」）。
