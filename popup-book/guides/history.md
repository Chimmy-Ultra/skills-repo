# 歷史、地理、人文

範例：`examples/bianjing`（《汴京一日》）。這類書是教材，**史實必須對**。

## 書的形式

- 右翻、直書：`book.json` 的 `"binding": "right"`，封面 `"style": "slip"`（左側題簽）+ `"seal"`（一個字的紅印）。
- 每個跨頁用 `textBlocks({ x, y, title, time, body, caption })`：標題、時辰（或年代、地點）、正文 5 欄、旁註（原典引文）。
- 結構建議：一條時間線或一條路線串起來。《汴京一日》是「一天」：卯時城門 → 辰時宣德樓 → 巳時相國寺 → 申時虹橋 → 酉時瓦子 → 戌時州橋夜市，光線跟著時辰變。
- 平面圖畫地理：街道走向、河道、城牆、圍牆；立起來的是建築正立面、人、車船。

## 正文和旁註

- **正文**：敘事，有畫面感，短句。可以寫氛圍（「霧還貼著蔡河」），但不能捏造具體史實（人名、數字、事件）。
- **旁註**：原典引文 + 一句背景。引文用『』，每一句都要逐字對過原典。
- 標籤（`tagMesh`）用原典裡的名稱（「庭中　彩幕露屋義鋪」、「爊肉」），讓機關本身就是在讀原典。

## 核對（每一句都要做）

1. 原典全文從維基文庫（zh.wikisource.org）、中國哲學書電子化計劃（ctext.org）用 WebFetch 讀，逐字比對引文。
2. 注意**版本異文**：同一句在不同版本用字不同（「爊肉」維基文庫本、別本作「熝肉」；「旋煎羊、白腸」斷句不同）。選一個版本，記在 `sources.md`。
3. 注意**指涉範圍**：例如「其中大小勾欄五十餘座」說的是桑家瓦子、中瓦、裡瓦三個加起來；「象棚」在裡瓦子。不要把整體的數字安到其中一個身上。
4. 時代要對得上：場景是哪一年、哪個季節；正文的季節景物（梨花、荷葉）和原典的時間（「宣和間盡植蓮荷」）有沒有衝突。旁註提到的另一件事（政和二年的瑞鶴）要標明年份。
5. 畫面的時代特徵：官服顏色、建築形制、器物。在 prompt 的領域規則段寫清楚，生回來的圖逐張檢查（明清特徵混進宋代是最常見的錯）。

## 機關：讓原典裡寫的事發生

好的機關本身就在重演一段文字：

| 原典 | 機關 |
|---|---|
| 「出朱雀門，直至龍津橋」 | 點城門，門打開，駝隊沿御街走出城 |
| 《瑞鶴圖》題跋「群鶴飛鳴於宣德門上」「二鶴對止於鴟尾之端」 | 點宣德樓，鶴群盤旋，兩隻停上鴟尾、面對面，最後往西北飛走 |
| 「相國寺每月五次開放萬姓交易」，各區賣什麼 | 點大三門，攤子照原典順序一區一區冒出來，浮出原典品名 |
| 《清明上河圖》虹橋下放桅 | 拖漕船靠近虹橋，船工放倒人字桅才過得去 |
| 「影戲」 | 點影戲棚，布幕亮起來演一段 |
| 「自州橋南去，當街水飯、爊肉、乾脯」 | 點燈籠，燈從州橋往南一盞盞亮，攤子浮出品名 |

## 常見的錯

- 把同一頁的地理方向畫反（河往哪流、門朝哪開）。平面圖北在上，卡片面向南。
- 南北向的東西（橋、長廊）用卡片立：看到的會是它的端面，不是側面。要畫在平面上，需要時另外印一張立面小插圖。
- 圖裡出現文字（生圖工具會亂寫招牌字）：prompt 一定要 `NOTEXT`，生回來再檢查。
