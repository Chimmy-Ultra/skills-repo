# 多益 Part 1 看圖練習：美術素材 toeic-art-1

## Instructions for Codex

Generate every image listed below and save them as PNG files in a new folder named `toeic-art-1/`.

1. Use each entry's prompt exactly as written, at its size, with the highest quality setting available. If a larger size with the same aspect ratio is available, use the larger one.
2. When transparent_background is true and the image tool supports it, request a transparent background; otherwise keep the pure white background the prompt asks for.
3. Style lock: generate `01-office-people.png` first. Then attach it as a reference image to every other entry, if the tool accepts input images, and append: "Match the drawing style, line weight and colour palette of the reference image exactly; do not copy its subject."
4. Check every result by looking at it. Regenerate (up to 3 attempts per entry) when any of these is true:
   - it contains any writing: characters, letters, numbers, seals, signatures or watermarks;
   - the subject is cut off by or touches the image edge (except 17-park-wall, 19-cover, which are meant to reach the edges);
   - a subject meant as a flat front elevation is drawn in perspective or three-quarter view, or there is ground, a cast shadow or background scenery;
   - subjects on a sheet overlap each other;
   - a person's hands are not on the object of their action, or the action could be read two ways;
   - a screen, board, sign, label or menu shows letters, numbers or a logo;
   - in the before / after pairs (03, 06, 09, 12, 15, 18) the two states are not clearly the same object, or the difference is hard to see;
5. Keep the exact file names. Do not crop, upscale, recolour or otherwise post-process.
6. When finished, write `toeic-art-1/manifest.txt` listing each file, its final size and how many attempts it took, then zip the folder as `toeic-art-1.zip`.
