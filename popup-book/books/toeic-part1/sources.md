## 考試格式

- **IIBC（日本 TOEIC 主辦單位）TOEIC Listening & Reading Test 題型頁**：Part 1 共 6 題；"Four short statements regarding a photograph will be spoken only one time." "The statements will not be printed."
  https://www.iibc-global.org/english/toeic/test/lr/about/format.html
- **ETS, TOEIC Examinee Handbook — Listening & Reading（© 2013 ETS）**：Part 1 說明 "you will hear four statements about a picture in your test book … select the one statement that best describes what you see in the picture."；13 類內容範圍（Corporate Development、Dining Out、Entertainment、Finance and Budgeting、General Business、Health、Housing/Corporate Property、Manufacturing、Offices、Personnel、Purchasing、Technical Areas、Travel）。
  https://www.muvs.cvut.cz/wp-content/uploads/2015/04/TOEIC-Listening-and-Reading-Examinee-Handbook.pdf

場景對應：辦公室 = Offices；工地 = Housing/Corporate Property（construction）；機場 = Travel；餐廳 = Dining Out；商店 = Purchasing（shopping）。公園不在 ETS 的表裡，是本書另加的戶外場景。

## 陷阱與文法

- **being / been**：照片裡沒有人時，"are being set up" 通常是錯的，"have been set up" 才是完成狀態。另有同音或發音相近的字（walking / working、copy / coffee、cart / card）、名詞對但動詞錯（腳踏車停著 ≠ "A man is riding a bicycle"）、說了照片看不出來的事（心情、理由、之前之後）。
  open-exam-prep, *Part 1 – Photographs: Actions, Objects, and Description Traps*
  https://open-exam-prep.com/study-guides/toeic/listening-photographs-question-response/photographs
- **being displayed 的例外**：「例外として、『物の状態』を示す場合は、必ずしも人が写っている必要はありません。」例：being displayed（展示されている）。
  スタディング《TOEIC Part 1》https://studying.jp/toeic/about-more/part1.html
- **wearing vs putting on**："*Wearing* is a state: the item is already on the body. *Putting on* and *taking off* are movements."
  open-exam-prep, *Action Verbs & Present Continuous Forms*
  https://open-exam-prep.com/study-guides/toeic-bridge-listening-reading/listening-part-1-photographs/action-verbs-present-continuous
